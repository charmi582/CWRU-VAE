# 乾淨版 Overleaf 中文稿

這份專案刻意不使用 Springer `sn-jnl`，避免中文與 Springer class 的相容性問題。

## 使用方式

1. 將整個 zip 上傳 Overleaf。
2. Main document 選 `main.tex`。
3. Compiler 選 `XeLaTeX`。
4. 按 `Recompile from scratch`。

## 主軸

- 嚴格泛化驗證
- Paderborn 外部資料集
- threshold calibration
- fuzzy health index
- 可重複實現流程

聯邦式學習不放入本文主軸，保留為下一篇研究。
